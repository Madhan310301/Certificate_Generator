# Google Fresher's Fuse 2026 Certificate Generator

A simple certificate generator for the Google Fresher's Fuse 2026 event, organized by the Google Student Ambassador Program at Bharath Institute of Higher Education and Research (BIHER).

## Features

- Generates participation certificates with official event branding
- Renders certificates directly in the browser
- Scales long names to fit the certificate layout
- Downloads certificates as PNG files
- Responsive layout for mobile and desktop screens

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Run Locally

### Requirements

- Node.js 18 or newer
- [pnpm](https://pnpm.io/)

### Setup

```bash
git clone https://github.com/Madhan310301/Certificate_Generator.git
cd Certificate_Generator
pnpm install
pnpm dev
```

Open `http://localhost:5173` in your browser.
